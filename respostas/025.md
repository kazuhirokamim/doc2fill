# Respostas do TearForm - Issue #1 / Feature 025: Engine Híbrida de Escaneamento

## 1. Problema e Justificativa
Escaneamento de documentos físicos complexos (fotos de celular tortas, cupons desbotados) com baixa acurácia no Tesseract WASM puro.

## 2. Decisão Ratificada
Arquitetura Híbrida: Local-First primário (binarização Otsu + rotação EXIF) + Cloud-Boost opt-in sob demanda com Zero Retenção.

## 3. Conformidade
LGPD compliant, Zero Retenção em disco no backend, 100% de testes TDD verdes.
